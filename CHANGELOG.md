## [1.1.0] - 2026-10-23

### Добавлено
* **Длины костей из реального скелета VRM**: устранены захардкоженные константы длин рук; длины `L1` (плечо-локоть) и `L2` (локоть-запястье) автоматически вычисляются в 3D мировом пространстве нормализованного скелета для каждой руки отдельно при каждой смене модели (`loadVRM` и Drag-and-Drop).
* **Стабильный масштаб пользователя**:
  * Масштаб рассчитывается по ширине плеч (`shoulderWidthAvatar / shoulderWidthUser`) по ориентирам 11 и 12 MediaPipe Pose.
  * Фильтрация скользящей медианой по окну ~2 секунды (120 кадров) при видимости обоих плеч > 0.6.
  * Кнопка «Калибровка (T-поза)» с 3-секундным таймером и фиксацией в `localStorage`.
* **Защита от переразгибания IK и слайдер Reach Multiplier**:
  * Ограничение досягаемости `0.98 * (L1 + L2)`, предотвращающее заклинивание двухкостного IK в выпрямленном состоянии.
  * Демпфирование Z-координаты вебкамеры с множителем `0.4x` для устранения ракурсных искажений.
  * Слайдер «Reach multiplier» (от 0.8x до 1.5x, по умолчанию 1.15x) с сохранением в `localStorage`.
* **Режим касания лица (Face-Touch Mode)**:
  * Анализ 2D-координат запястья (точка 0) и центра ладони (среднее точек 0, 5, 17) относительно точек лица FaceMesh (нос 1, лоб 10, подбородок 152, щеки 234 и 454).
  * Гистерезис активации: включение при расстоянии < 0.25 от высоты лица, выключение при > 0.35 для предотвращения мерцания.
  * Экспоненциальное сглаживание перехода (~120 мс) с отступом наружу 0.025 м от поверхности меша.
  * Независимое состояние для левой и правой руки.
* **Анатомические ограничения локтя и Pole Vector**:
  * Кеширование вектора направления локтя с fallback при видимости < 0.5.
  * Анатомический ограничитель, предотвращающий проваливание локтя в торс или выворачивание вверх.
* **Мягкие коллизии с головой**:
  * Сфера головы радиусом 0.07 м для кистей и запястий, плавно ослабляемая в режиме касания лица.
* **Фильтр 1€ (One Euro Filter)**:
  * Реализация адаптивного низкочастотного фильтра (`src/oneEuroFilter.ts`) для сглаживания позиций запястий и локтей без задержки при быстрых движениях.
* **Панель отладки (Debug HUD)**:
  * Включение/выключение по клавише `D` или кнопке «Отладка» в верхнем меню.
  * Отображение текущего FPS, времени обработки кадра, параметров масштаба, длин рук, весов касания лица и видимости суставов.
  * 3D-сферы целевых точек запястий на сцене.
* **Режим OBS Browser Source**:
  * Переключатель прозрачного фона для стриминга.
  * Поддержка параметра URL `?obs=true` для автоматического прозрачного запуска без интерфейса.

### Оптимизация
* **Устранение аллокаций в горячем цикле (Zero Allocation)**:
  * Замена регулярных вызовов `new THREE.Vector3()` и `new THREE.Quaternion()` внутри кадров рендера и IK на переиспользуемые статические векторы и кватернионы (`_scratchV1`, `_scratchQ1` и др.).

## [1.0.0] - 2026-10-23

### Добавлено
* Первый стабильный автономный релиз VTuber Studio Pro.
* Полная поддержка 52 блендшейпов Apple ARKit (Perfect Sync) для модели «Розовая Гяру».
* Поддержка стандартных эмоций для классических VRM 0.x и 1.0 моделей.
* Двухкостный IK для рук с трекингом 21 сустава кисти и пальцев.
* Встроенный портативный веб-сервер Node.js (`server.cjs`) и нативный веб-сервер Windows PowerShell (`server.ps1`).
* Drag-and-drop загрузка любых пользовательских `.vrm` файлов.
