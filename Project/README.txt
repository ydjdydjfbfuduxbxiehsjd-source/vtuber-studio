VTuber Studio Pro — Portable Windows

Запуск
1. Скопируйте VTuber-Studio-Pro-Portable.exe на компьютер с Windows 10/11 x64.
2. Запустите файл двойным щелчком. Установка Node.js, npm и зависимостей не нужна.
3. Нажмите «Запустить отслеживание» и разрешите приложению доступ к камере.

Готовый файл в этой папке: VTuber-Studio-Pro-Portable.exe.

Приложение включает веб-интерфейс и его локальные ресурсы, включая MediaPipe и демонстрационную VRM-модель. После сборки интернет для работы не требуется. Видео обрабатывается локально.

Сборка разработчика
- Исходная веб-сборка хранится в папке dist рядом с этим файлом.
- Для создания EXE в этой папке выполните: npm install, затем npm run build:portable.
- Скрипт сборки скачает Electron только для процесса сборки; готовый EXE не требует этого шага при запуске.
- Готовый EXE создаётся в папке release-exe.

Сборка предназначена для Windows x64. Файл не подписан цифровым сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen.
